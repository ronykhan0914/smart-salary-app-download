Push Notification পরীক্ষা

Admin only · সব subscribed device

এই পরীক্ষা সব সক্রিয় Push Subscription-এ একটি সাধারণ Test Notification পাঠাবে। কুরআন/হাদিসের দৈনিক কনটেন্ট পাঠাবে না। প্রতি ৫ মিনিটে একবার পাঠানো যাবে।

পাঠানোর আগে ফোনগুলোতে অ্যাপ/ওয়েব অ্যাপের Notification Permission Allow এবং Push Subscription সক্রিয় থাকতে হবে।
